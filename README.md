# Hytham Studios

A premium, cinematic website for Hytham Studios built with React, Vite, and Tailwind CSS v4.

## Getting Started

1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to start the development server.

## Features

- **React + Vite:** Blazing fast development server and optimized production build.
- **Tailwind CSS v4:** Modern styling with a custom Dark Monochrome theme.
- **Premium Aesthetics:** Cinematic micro-animations, sleek typography (`Inter` & `Syncopate`), and beautiful layouts.
